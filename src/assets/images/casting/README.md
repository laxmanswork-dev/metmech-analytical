# Casting page hero photograph

Save the photograph here as `casting-hero.webp` (or `casting-hero.jpg`):
a 4:3 casting-process photograph, about 1200 x 900 pixels. The casting
page (`/casting-services`) shows it at the right of its hero on the next
build; until then the hero shows an empty 4:3 frame.

Then describe the photo in `casting.hero.imageAlt` in
`src/i18n/translations/en/casting.js` and `ta/casting.js`.

The lookup is `CASTING_HERO_IMAGE` in `src/data/images.js`.
